# 让交付可验证：四模型验收修复实验

新增模型验收证据：[GLM-5.3 四路工程对照](model-review-report.html)，12 个样例、48 次运行；与本文此前的 L1 统计及机制测试分别报告。

**主结果：Llama 3.2 3B 从 3.8% 到 35.8%，提升 32 个百分点。**

原汇总生成时间：2026-09-11T19:47:54.632Z；口径修订：2026-09-12。本次仅复核既有数据，没有新增模型请求或更改原始记录。

## 先读结论

- 验收与有界修复在所测 Llama 3B、Qwen Coder 7B 上增加了正确交付；MiniCPM 1B、Qwen 1.5B 的提升未达到显著水平。收益依赖模型、任务和配置。
- 三次投票也有优势场景：Llama 匹配子集 C 高于 B；Qwen Coder 匹配子集 B 高于 C。现有数据不支持修复总是最优。
- 所有统计只测 **L1 确定性验收 + 修复**，L2 模型评审关闭。双层模型核查的证据另见真实演示，不能借用本表当作 L2 效果评测。

## 设计与规模

1,450 是四模型合计的 A/B 配对数，不再乘以模型数。C、D 各 1,000 条任务记录；E 从 C 候选事后推导。

| 组别 | 策略 | 计数与成本口径 |
|---|---|---|
| A | temperature 0、seed 42，单次尝试，maxRepairs=0 | 1,450 个任务 |
| B | 首答逐字回放 A；后续 temperature 0.7、不固定 seed；最多 2 次修复，总轮次 6 | 与 A 配对；逻辑请求、token 包含回放首答 |
| C | 同温度 0.7 独立采样三次，多数投票；无多数时取首个可解析候选 | 1,000 个任务，每题三次采样 |
| D | temperature 0.7 单次采样，文本解析 | 1,000 个任务 |
| E | 用标准答案选择 C 中最早正确的候选 | 事后分析，未新增模型执行 |

任务由确定性生成器产生并计算标准答案；所有组按最终值与标准答案完全相等判分。A/B 运行时也使用这个确定性检查器。C/D 只在最终分析时使用相同判分标准。四类任务合并为分段计价、多条件筛选、支付订单和退款计算；每个模型覆盖其中三类。任务经过难度校准，不能代表自然业务任务的总体分布。

## 解释与限制

- A/B 首答完全相同，但 B 增加了采样、反馈和上下文；C/D 的输出通道和策略也不同。结论针对整个方案，不能单独归因于反馈或所谓锚定效应。
- B 保留 A 已通过的首答，因此没有 A 过/B 败受到设计保障；它不是通用的生产零回归保证。
- McNemar 精确检验用于配对二元结果。p 值是在零假设及检验假设成立时出现当前或更极端结果的概率，不是零假设本身的概率。多模型、多组比较未做多重比较校正，按探索性证据解读；也未建模任务族内相关性。
- 已有主实验未排除基础设施错误记录（排除数为 0）。脚本仍有保留与排除基础设施失败的策略，数据包中可查。
- 校准记录保留了所选难度的依据；这不是随机抽取的真实业务分布，不能外推为自然任务成功率。模型量化、运行时、GPU 和驱动也影响复现。
- taxonomy 中按字段正确与否划分错误是启发式标签，不证明模型内部是否理解规则；不同修复策略结果也不足以证明锚定因果。
- 没有双层验收的大样本增益、白盒记忆学习收益、旗舰模型替代或同条件竞品性能实验。
